# 🎨 Nutrinous Supplements Color Palette

تم تطبيق لوحة الألوان الجديدة على المشروع.

## الألوان الأساسية

### Primary Colors
- **Primary (340B8C)**: اللون الأساسي - يستخدم للأزرار والعناصر الرئيسية
- **Secondary (201240)**: اللون الثانوي - للعناصر المهمة
- **Tertiary (2F1B59)**: للعناصر الإضافية

### Light & Dark
- **Light (F2D5F2)**: للخلفيات الفاتحة والـ accents
- **Dark (120426)**: للنصوص الداكنة والخلفيات

## الاستخدام في Tailwind

```jsx
// الألوان الأساسية
className="bg-primary text-white"
className="text-primary"
className="border-primary"

// الألوان الفاتحة
className="bg-nutrinous-light"
className="bg-nutrinous-light/30" // مع opacity

// الألوان الداكنة
className="bg-nutrinous-dark"
className="text-nutrinous-dark"

// استخدام مباشر
className="bg-nutrinous-primary"
className="bg-nutrinous-secondary"
className="bg-nutrinous-tertiary"
```
