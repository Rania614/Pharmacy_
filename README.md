# Medifit - متجر إلكتروني للمنتجات الطبية والصحية

## نظرة عامة على المشروع

**Medifit** هو تطبيق ويب متكامل لتجارة إلكترونية متخصص في بيع المنتجات الطبية والصحية. المشروع مبني باستخدام **React** و **Vite** مع واجهة مستخدم حديثة وسريعة الاستجابة.

## المميزات الرئيسية

### 🏠 الصفحة الرئيسية (Home)
- **Hero Section**: قسم رئيسي جذاب يعرض العروض والمنتجات المميزة
- **التصنيفات**: عرض 6 تصنيفات رئيسية:
  - الأدوية (Medicine)
  - العناية الصحية (Health care)
  - العناية بالجمال (Beauty care)
  - اللياقة البدنية (Fitness)
  - معدات المختبرات (Lab equipment)
  - مجموعات طبية (Med Kits)
- **مجموعات ترويجية**: عرض 3 مجموعات خاصة:
  - مجموعة الأجهزة الطبية
  - مستلزمات العناية الصحية
  - المجموعات الطبية الاحترافية
- **أحدث المنتجات**: عرض 4 منتجات مميزة على الصفحة الرئيسية
- **مميزات إضافية**: عرض ضمان 30 يوم، سياسة الاستبدال، الدفع الآمن

### 🛍️ صفحة المنتجات (Products)
- **عرض جميع المنتجات**: عرض شامل لجميع المنتجات المتاحة (12 منتج)
- **البحث**: إمكانية البحث عن المنتجات بالاسم
- **التصفية**: تصفية المنتجات حسب التصنيف
- **الترتيب**: إمكانية ترتيب المنتجات حسب:
  - الاسم
  - السعر (من الأقل للأعلى)
  - السعر (من الأعلى للأقل)
  - التقييم
- **وضع العرض**: إمكانية عرض المنتجات في وضع الشبكة (Grid) أو القائمة (List)
- **عرض عدد النتائج**: عرض عدد المنتجات المطابقة للبحث

### 🛒 صفحة السلة (Cart)
- **إدارة السلة**: عرض جميع المنتجات المضافة للسلة
- **تعديل الكمية**: زيادة أو تقليل كمية المنتجات
- **حذف المنتجات**: إمكانية حذف المنتجات من السلة
- **ملخص الطلب**: عرض:
  - المجموع الفرعي
  - تكلفة الشحن (مجاني للطلبات فوق $50)
  - الضريبة (8%)
  - الإجمالي النهائي
- **كود الخصم**: إمكانية إدخال كود خصم
- **الدفع**: زر للمتابعة إلى صفحة الدفع

### 💬 مساعد الذكاء الاصطناعي (AI Chat)
- **دردشة تفاعلية**: مساعد ذكي للرد على استفسارات العملاء
- **واجهة حديثة**: تصميم عصري وسهل الاستخدام
- **رسائل فورية**: ردود فورية على استفسارات المستخدمين

### 🧩 المكونات (Components)
- **Header**: رأس الصفحة مع:
  - شعار الموقع
  - قائمة التنقل
  - شريط البحث
  - أيقونات المستخدم والسلة
  - قائمة متجاوبة للهواتف المحمولة
- **Footer**: تذييل الصفحة مع معلومات الاتصال والروابط
- **ProductCard**: بطاقة عرض المنتج مع:
  - صورة المنتج
  - الاسم والسعر
  - التقييمات
  - علامات الخصم والجديد
- **CategoryCard**: بطاقة عرض التصنيف
- **HeroSection**: قسم البطل الرئيسي

## التقنيات المستخدمة

### المكتبات الأساسية
- **React 19.1.0**: مكتبة JavaScript لبناء واجهات المستخدم
- **React Router DOM 7.6.0**: للتنقل بين الصفحات
- **Vite 6.3.5**: أداة بناء سريعة وحديثة

### التصميم والأنماط
- **Tailwind CSS 3.4.17**: إطار عمل CSS للتصميم السريع
- **Tailwind CSS Animate**: لإضافة الحركات والانتقالات
- **Lucide React**: مكتبة أيقونات حديثة

### الأدوات المساعدة
- **Axios 1.9.0**: لطلبات HTTP (جاهز للاستخدام مع API)
- **ESLint**: لفحص جودة الكود
- **PostCSS & Autoprefixer**: لمعالجة CSS

## البيانات الحالية

- أدوية (Asthma Inhaler)
- مستلزمات صحية (Medical Gloves, Face Mask, Hand Sanitizer)

## التثبيت والتشغيل

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **تثبيت المكتبات**:
```bash
npm install
```

2. **تشغيل المشروع في وضع التطوير**:
```bash
npm run dev
```

3. **بناء المشروع للإنتاج**:
```bash
npm run build
```

4. **معاينة البناء**:
```bash
npm run preview
```

5. **فحص الكود**:
```bash
npm run lint
```
